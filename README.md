# Khaemrekh · scheda di Kem

Scheda interattiva di Kem, Necron Scuoiatore monaco dell'Ombra di 6° livello. Funziona anche offline su iPad.

## Pubblicarla su GitHub Pages
1. Crea un repository (es. `kem`) e carica tutti i file di questa cartella nella radice.
2. Vai in **Settings → Pages**, scegli **Deploy from a branch**, branch `main`, cartella `/ (root)`, e salva.
3. Dopo un minuto la scheda è online su `https://<tuo-utente>.github.io/kem/`.

## Installarla sull'iPad
1. Apri l'indirizzo in **Safari**, con la connessione attiva.
2. Tocca **Condividi → Aggiungi alla schermata Home**.
3. Aprila una volta dall'icona: da quel momento funziona anche senza rete.

PF, risorse, zaino e note restano salvati sull'iPad.

## Aggiornarla
Sostituisci `index.html` e in `sw.js` cambia `kem-v1` in `kem-v2` (e così via). Alla prossima apertura online l'iPad scarica la nuova versione.
